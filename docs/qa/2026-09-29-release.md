## 浏览器操作与视觉检查

使用应用内浏览器，在 localhost 独立测试数据上验证：

- 新建空白简历、填写姓名、立即进入网页预览、返回、刷新，内容保留。
- 重置样例前出现确认；恢复点保留原稿，恢复及撤销结果正确。
- 编辑/预览模式切换，预览中的侧栏按钮可返回编辑。
- JSON 导出入口正常触发；长页 PDF 实际生成流程完成，无错误提示。
- 照片显示、隐藏、移除与单次撤销恢复；无照片时显示上传入口。
- 桌面 1280px，手机 390px 与 320px 截图检查：顶栏单行、菜单不换行、表单单列、导出弹窗可操作，无页面横向溢出。
- 照片区布局紧凑；已移除底部栏目跳转下拉框。
- 修复网页预览“返回编辑”链接的 Base UI nativeButton 语义警告。

## 验证范围

本轮为实际浏览器操作验收，不是新增 Playwright CI 测试套件。JSON 导入的数据校验与替换保护由自动化测试覆盖，未操作系统文件选择器。A4 分页与打印准备由自动化测试覆盖，本轮未验证实体打印、iOS Safari 原生打印窗口或真实软键盘。视觉检查为截图人工检查，未建立像素差异基线。
