## 构建体积

单位为十进制 kB。下表是脚本与样式的构建大小，不是网络耗时或完整首访流量。

| 产物 | 重构前 | 重构后 |
| --- | ---: | ---: |
| 主脚本 | 930.69 | 495.52 |
| 主脚本 gzip（构建工具报告） | 413.24 | 162.22 |
| 编辑器全部必要脚本，含拆分文件及共享依赖 | 930.69 | 561.94 |
| 编辑器全部必要脚本 gzip（体积检查脚本） | 约 413 | 180.32 |
| CSS | 60.96 | 53.48 |
| Worker | 53.84 | 0.57 |

当前编辑器全部脚本 gzip 约减少 56%。基线压缩值来自原构建输出，当前总量由 Node gzip 累计，压缩实现可能有小幅差异。

示例文件仍为 371.40 kB，gzip 234.03 kB。已有草稿用户不需要它；新用户仍需额外下载，因此不能将以上脚本下降比例当作首次总下载量下降比例。jsPDF 与截图模块依旧在图片 PDF 导出时加载。

构建没有超过 500 kB 的脚本，也没有大包警告。预算：编辑器总脚本不超过 600 kB / gzip 200 kB，单脚本不超过 500 kB。
