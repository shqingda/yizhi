## 使用简历编辑器

| 地址 | 用途 |
| --- | --- |
| `/` 或 `/editor` | 填写内容、调整栏目与版式。 |
| `/resume` | 阅读当前浏览器的简历，缩放、导出、返回编辑。 |

首次进入加载示例，有本机草稿则直接继续。通过“更多 → 管理简历”空白新建、命名、复制或切换。示例只在首次使用和重置时请求；网络失败会提示重试，不替换已有草稿。

联系信息与栏目可拖动排序：移动超过 8px 后跟随指针，松手完成，Escape 可取消；也可聚焦手柄用上下方向键移动，一次拖动只需一次撤销。经历保留上下移动按钮，可折叠、复制；新增后聚焦首字段。日期支持年月和“至今”，保留旧自由文本。照片支持 JPG、PNG、WebP，最大 10 MB，裁剪后按 480×600 压缩保存。

手机通过顶栏“编辑 / 预览”切换，独立网页预览入口在“更多”中。预览中可缩放、双击栏目回到编辑；桌面保留侧栏折叠按钮。顶栏主题菜单支持浅色、深色和跟随系统，纸张与导出始终白底。

### 保存、恢复与备份

- 停止编辑约 350ms 后自动保存。顶栏显示当前简历名称和保存状态，只有写入成功才显示“已保存到本机”；写入失败时页面直接显示提示，可下载当前稿 JSON 或重试。
- 同一浏览器和站点只允许一个页面编辑；其他页面直接预览已保存内容，可导出。关闭原编辑页后，点击“在此编辑”继续，不会强制抢占。当前浏览器不能使用 Web Locks 时，只提供预览与备份。
- 如果旧版本页面或其他来源绕过编辑锁更新记录，当前页会暂停保存并保留本页修改。先下载当前稿 JSON，再刷新读取已保存版本；需要保留两份时，将备份导入并选择“另存为新简历”。
- 工具栏提供整份简历的撤销和重做，输入框保留系统文字撤销。
- 删除通知可恢复被删条目；导入、重置、恢复旧稿之前先创建持久恢复点。
- 每份简历最多 5 个恢复点，总恢复点容量按 UTF-16 字符估算限制为 2 MiB。备份失败会阻止替换。
- JSON 导入先展示摘要，再选择替换或另存新稿；文件上限 5 MB。
- 不同浏览器、设备、网站地址的数据独立。换设备前导出 JSON；清除浏览器数据会同时清除草稿和恢复点。

输入框外可用 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z 撤销重做，Cmd/Ctrl+B 切换编辑栏；Cmd/Ctrl+S 尝试保存。

如果提示“无法读取本机草稿”，保留浏览器数据，检查存储权限后刷新。应用不会用示例覆盖损坏记录；此时导出的当前临时内容不等于恢复了旧数据。

### 网页预览和 PDF

编辑页与网页预览共用同一工作区及编辑权，切换页面不释放锁，返回后仍可撤销。其他只读页面会跟随已保存内容更新。地址不用于分享个人内容，其他人打开时看到他们自己浏览器中的数据。

| 导出格式 | 结果 |
| --- | --- |
| A4 PDF（文字内容） | 打开浏览器打印，选择另存为 PDF，通常保留可复制文字。 |
| 长页 PDF（图片内容） | 下载包含整页截图的 PDF，文字不能选中，不是 PNG/JPG 文件。 |

导出窗口使用打开时的简历副本，切换导出格式不改变草稿版式；只读页也可以独立选择格式。

A4 打印选择 A4 纸张、100% 缩放、关闭页眉页脚。文件名是建议值，实际名称由浏览器打印窗口决定。超长经历、长网址和字体替换可能影响最终分页，保存前检查每一页。

已加载页面可本机编辑；首次加载示例、首次加载图片 PDF 依赖需要网络，未实现完整离线刷新。JSON 是可继续编辑的备份，PDF 用于阅读和投递。

## 本地开发

```bash
pnpm install --frozen-lockfile
pnpm dev
```

访问 [本地编辑器](http://127.0.0.1:45221)。端口固定为 45221，若占用先检查已有服务。

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 本地前端与 Worker 开发。 |
| `pnpm test` | Vitest 自动化测试。 |
| `pnpm run build` | 类型检查与生产构建。 |
| `pnpm check` | 类型、测试、生产构建及包体积预算。 |
| `pnpm run check:bundle` | 检查已有生产产物及示例大小，修改代码后需先重新构建。 |
| `pnpm preview` | 构建后运行生产预览。 |

不需要数据库或认证服务。前端主要代码在 `src/app`，数据类型和分页计算在 `src/shared`。文件定位见 [架构模块表](architecture.md#2-模块职责)。

## Cloudflare 部署

`wrangler.toml` 已设置 Worker 名称、静态资源目录和 SPA 回退。确认发布目标后运行：

```bash
pnpm check
pnpm run deploy
```

使用 `pnpm run deploy`，避免误调用 pnpm 自带的同名命令。首次部署到自己的账号先运行 `pnpm exec wrangler login`，并修改 Worker 名称。

当前没有 D1 绑定、数据库迁移或邮件配置。仓库清理不会删除远端历史数据库。旧云端接口仍返回 410；`/api/health` 返回 `storage: "browser"`。发布后验证编辑、刷新、预览、JSON 导入导出和 PDF。

## 修改样例与功能

默认样例唯一来源是 [public/sample-resume.json](../public/sample-resume.json)，照片以内嵌数据保留，整个文件可直接导入。更新它不会覆盖已有草稿；在编辑器重置示例后才能看到新模板。

| 修改内容 | 入口 |
| --- | --- |
| 新增字段、兼容旧 JSON | `src/shared/schema.ts` 与对应 `forms/*Form.tsx`。 |
| 新增栏目表单 | `components/editor/forms`、`EditorForms.tsx` 映射、`EditorPage.tsx` 栏目导航。 |
| 显示和排版 | `ResumeDocument.tsx` 与 `index.css`。 |
| 保存、恢复、多份草稿 | `useResume.ts`、`workspaceLease.ts`、`draftStore.ts`。 |
| 启动和示例请求 | `initializeWorkspace.ts`、`sampleResume.ts`。 |
| JSON 与 PDF | `resumeFiles.ts`、`exportResume.ts`。 |

## 常见问题

**换设备怎么继续？** 在原设备导出 JSON，到新设备导入；没有云端同步。

**隐藏内容等于删除吗？** 不等于，隐藏只影响展示，JSON 和本机草稿仍可能包含原值。

**刷新后还能撤销吗？** 普通会话历史不能；导入、重置等重要操作前的恢复点可以。

**为什么新样例没有生效？** 页面优先读取已保存草稿。修改模板后使用“重置示例”，当前稿会先创建恢复点。

**为什么长页 PDF 不能复制文字？** 它由截图生成；需要可复制文字时使用 A4 打印路径。
