## 保持的边界

- Web Locks 保证遵守同一锁的新页面互斥；旧版本页面或外部来源仍由快照比较防御，但不提供对这些来源的跨版本原子事务或自动合并。
- 账号、云同步、公开分享、AI、更多模板、协作、照片拖拽增强不属于本轮。
- IndexedDB / 容量迁移、完整持久历史、完整离线缓存为后续增强，尚未实施。
- 保留全部原有未提交改动；本轮没有迁移数据库或发布生产。

## 回归方式

运行 `pnpm check` 检查类型、全部测试、生产构建和体积；预算继续累计静态共享依赖和 Motion，不通过拆出新文件隐藏体积增长。UI 检查编辑 → 保存 → 双页同步 → 关闭接手 → 排序取消 / 撤销 → 导出 → 返回与刷新。历史结果只代表对应日期与产物。
