## 已交付

| 使用流程 | 当前能力 |
| --- | --- |
| 开始填写 | 首次载入示例；已有草稿继续；可空白新建、命名、复制和切换。 |
| 放心保存 | 本机自动保存、错误提示、旧草稿读取、配额失败保护。 |
| 放心修改 | 撤销重做、删除恢复、导入确认、替换前恢复点、JSON 备份。 |
| 高效编辑 | 经历折叠与复制、日期辅助、排序与隐藏、照片裁剪旋转压缩。 |
| 预览与导出 | 当前稿预览、独立本机预览、缩放、A4 文字 PDF、长页图片 PDF。 |
| 手机和键盘 | 编辑 / 预览切换、窄屏顶栏、软键盘视区适配、键盘排序、焦点与标签。 |
| 外观 | 浅色、深色、跟随系统；简历纸张和导出保持白底。 |
| 维护与性能 | 表单按栏目拆分、共用草稿状态、示例按需加载、清理云端依赖、构建体积预算。 |

“已交付”表示代码已实现并有相应自动化或浏览器检查，不代表所有设备通过验收。

## 仍待验收

- [ ] iOS Safari / Android Chrome 真机：软键盘、触控拖动、焦点、返回编辑、打印窗口。
- [ ] 屏幕阅读器完成填写、排序、导入和导出的整条流程。
- [ ] 200% 浏览器缩放、长中文标签、减少动态效果设置下的操作可达性。
- [ ] 复杂 A4 最终 PDF：超长经历、长网址、照片、中文字体、多页逐页检查及实体打印。

桌面窄屏模拟不能替代手机系统键盘；自动化分页和 PDF 几何测试不能替代系统最终打印。每轮实际检查范围写入 `docs/qa/`，通过后再更新此处。

## 后续增强，尚未纳入交付

- 多标签页同时编辑的冲突检测和合并。
- IndexedDB 或其他容量方案；完整持久历史。
- 离线刷新与完整资源缓存。

AI 润色、评分、更多模板、协作和账号体系不在当前范围。不要把取消的云端阶段重新列成欠账。

## 验收方式

代码改动执行 `pnpm check`。涉及 UI 的改动检查新建 → 填写 → 切换栏目 → 预览 → 返回 → 刷新 → 导出；涉及保存的改动补充损坏数据、容量失败、恢复与草稿隔离检查。
